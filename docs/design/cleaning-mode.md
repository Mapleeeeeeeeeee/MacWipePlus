# MacWipePlus 清潔模式

## 背景與問題

使用者清潔 Mac 螢幕、鍵盤與觸控板時，抹布、清潔工具或手部容易觸發按鍵、點擊、手勢與系統快捷操作，造成誤操作。現有 MacWipe 的清潔模式概念符合需求，但自動退出時間固定、無法自行修改原始碼，也缺少可保存的時間偏好。

本功能要提供一個免費、可自行修改的 macOS 清潔模式 App。使用者啟用後看到黑色清潔畫面，裝置輸入暫時被攔截，清潔完成後可以安全退出；若不提供保底機制，異常狀況可能讓使用者失去輸入控制，因此解鎖與自動退出必須是核心安全功能。

## 使用者角色

一般 macOS 使用者：清潔筆電或桌機的螢幕、鍵盤、觸控板與滑鼠，核心動機是避免清潔過程觸發任何操作。

## 需求情境

- 使用者清潔 Mac 時，希望暫時停用所有可攔截的輸入，避免誤開程式、輸入文字或觸發快捷鍵。
- 使用者只想快速清潔，希望從選單列或快捷鍵立即進入清潔模式。
- 使用者需要不同長度的清潔時間，希望使用預設選項、自訂秒數或手動退出。
- 使用者重複使用 App 時，希望沿用上次選擇的清潔時間。
- 使用者需要在畫面全黑時仍知道目前狀態與退出方式，因此提醒與倒數必須在清潔畫面底部顯示。

## 設計意圖

- 使用黑色全螢幕清潔畫面 → 降低螢幕內容干擾，也讓清潔螢幕時更容易看見髒污。
- 使用底部小字顯示提醒與倒數 → 保留必要狀態資訊，但不讓文字成為清潔視覺的主要干擾。
- 長按 `Esc` 3 秒退出 → 避免單次誤觸就解除鎖定，同時保留不依賴滑鼠或觸控板的退出方式。
- 按住 `Esc` 時顯示 3、2、1 秒退出倒數 → 使用者能確認 App 正在收到長按，不會誤以為被鎖死。
- 同時支援選單列與全域快捷鍵啟動 → 兼顧可發現性與快速操作。
- 預設提供常用時間，也支援任意秒數與不自動退出 → 不用犧牲簡單操作，就能涵蓋不同清潔情境。
- 保存最後使用的時間 → 讓重複清潔時不必反覆重新設定。
- 不播放倒數提示音 → 清潔時保持安靜，且避免音效成為必要依賴。
- 強制結束 App 或重新開機後恢復正常輸入 → 清潔模式不能永久接管輸入，也不能讓使用者被鎖死。

## User Journey

### Journey 1：一般使用者 — 從選單列啟動清潔模式

前置條件：App 已開啟並顯示於選單列；使用者已完成必要的 macOS 權限授予。

1. 使用者點擊選單列圖示 → 顯示清潔模式入口與時間選擇。
2. 使用者選擇預設時間、自訂秒數或不自動退出 → App 顯示即將套用的時間。
3. 使用者啟動清潔模式 → 畫面進入黑色全螢幕清潔畫面，底部顯示目前狀態、剩餘時間與「長按 Esc 3 秒退出」提醒。
4. 使用者清潔螢幕、鍵盤與觸控板 → 可攔截的鍵盤、滑鼠、觸控板與 Touch Bar 輸入不應傳遞到其他 App。
5. 倒數結束 → 清潔模式自動退出，恢復一般輸入與原本的畫面。
6. 使用者再次開啟設定 → 預設選項帶入上次使用的時間。

### Journey 2：一般使用者 — 使用全域快捷鍵啟動

前置條件：App 已開啟；全域快捷鍵未與其他 App 衝突。

1. 使用者按下全域快捷鍵 → 直接以目前保存的時間進入清潔模式。
2. 使用者清潔設備 → 輸入被攔截，底部持續顯示狀態與倒數。
3. 使用者長按 `Esc` 3 秒 → 顯示退出進度，完成後離開清潔模式並恢復輸入。

### Journey 3：一般使用者 — 自訂與保存清潔時間

前置條件：使用者開啟時間設定。

1. 使用者選擇快捷時間 → App 保存該選擇。
2. 使用者輸入任意正整數秒數 → App 驗證輸入並保存有效值。
3. 使用者選擇不自動退出 → 倒數改為無限期，直到使用者長按 `Esc` 退出。
4. 使用者下次啟動 → App 使用上次有效的時間設定。

## 替代流程

- 使用者未授予 Accessibility 權限：App 仍進入清潔模式，使用全螢幕覆蓋視窗攔截一般鍵盤、滑鼠與觸控板輸入；授權後可啟用跨 App 的完整攔截。
- 使用者輸入無效秒數：保留目前有效設定，提示必須輸入正整數；不得以無效值啟動清潔模式。
- 全域快捷鍵衝突：提示快捷鍵不可用，允許使用者自訂其他組合或改從選單列啟動。
- 使用者在倒數結束前長按 `Esc`：完成 3 秒長按後立即退出，不必等待倒數結束。
- 使用者按下 `⌃ Control + ⌥ Option + ⌘ Command + Esc`：立即退出清潔模式；`⌥ Option + ⌘ Command + Esc` 保留給 macOS 的強制結束介面。
- 使用者選擇不自動退出：不顯示剩餘秒數，仍顯示清潔狀態與退出提醒。

## 錯誤情境

### 系統錯誤

- 權限在清潔模式啟動後被撤銷：App 應停止 Event Tap，但保留覆蓋畫面與一般輸入攔截；若覆蓋視窗也失效則退出清潔模式。
- App 發生錯誤或被強制結束：重新取得控制後，鍵盤、滑鼠與觸控板必須恢復正常。
- 系統不允許攔截電源鍵：不宣稱可阻擋電源鍵；其他能安全攔截的輸入仍照常處理。

### 使用者誤操作

- 使用者短按 `Esc`：不退出清潔模式。
- 使用者誤觸其他可攔截的按鍵或點擊：不應將輸入傳遞至背景 App；電源鍵、Touch ID 與其他 macOS 不允許一般 App 攔截的硬體事件不在保證範圍內。
- 使用者輸入 0、負數、小數、空值或過大的秒數：顯示驗證錯誤，不覆蓋既有有效偏好。

### 惡意行為

- App 不收集、記錄或傳送鍵盤內容、滑鼠操作或螢幕內容。
- App 不進行檔案清理、刪除資料或修改系統設定以外的功能。

## Out of Scope

- 無法可靠攔截的電源鍵行為。
- 磁碟清理、檔案刪除、系統最佳化或裝置維護功能。
- 倒數提示音、音效設定與通知音效。
- Touch Bar 以外的外接硬體專屬控制。
- 雲端同步、帳號、遙測、分析與遠端更新服務。
- Windows、Linux 與 macOS 12 以下版本。

## 整合點

- 平台：macOS 13 Ventura 以上。
- 介面：選單列 App 與全域快捷鍵。
- 系統權限：需要依實際攔截方式取得 macOS Accessibility／Input Monitoring 等必要權限，並在首次使用時清楚說明用途。
- 語言：繁體中文與英文，依 macOS 系統語言選擇；若無法判定則使用英文。
- 發布：提供可直接開啟的 `.app`；開發階段同時保留可自行編譯的專案原始碼。
- 偏好資料：本機保存最後有效的清潔時間與必要的 App 設定，不上傳任何資料。

## Acceptance Criteria

- Given App 已開啟
  When 使用者從選單列啟動清潔模式
  Then 畫面顯示黑色全螢幕清潔畫面，底部顯示語言正確的提醒與倒數

- Given 使用者已設定有效的清潔時間
  When 清潔模式啟動
  Then 可攔截的鍵盤、滑鼠、觸控板與支援的 Touch Bar 輸入不會操作背景 App

- Given 清潔模式正在執行
  When 使用者短按 `Esc`
  Then 清潔模式保持啟用

- Given 清潔模式正在執行
  When 使用者持續按住 `Esc` 3 秒
  Then 清潔模式退出並恢復正常輸入

- Given 清潔模式正在執行
  When 使用者按住 `Esc`
  Then 清潔畫面底部顯示 3、2、1 秒的退出倒數

- Given 清潔模式正在執行
  When 使用者按下 `Control-Option-Esc`
  Then 清潔模式立即退出，且 macOS 的強制結束快捷鍵仍可使用

- Given 使用者選擇 2 分鐘
  When 清潔模式啟動且沒有提前退出
  Then 約 2 分鐘後自動退出並恢復正常輸入

- Given 使用者選擇不自動退出
  When 清潔模式啟動
  Then 清潔模式不因時間經過自動退出，直到使用者長按 `Esc`

- Given 使用者輸入有效的自訂秒數
  When 儲存並啟動清潔模式
  Then App 使用該秒數倒數，且下次開啟時仍帶入該設定

- Given 使用者輸入無效秒數
  When 嘗試儲存或啟動
  Then App 顯示驗證錯誤，且不覆蓋上次有效設定

- Given 使用者輸入 9 秒、0 秒、負數、小數、空值或超過 3,600 秒
  When 嘗試儲存或啟動
  Then App 顯示驗證錯誤，且不覆蓋上次有效設定

- Given 使用者輸入 10 秒或 3,600 秒
  When 儲存並啟動清潔模式
  Then App 接受該設定並依指定秒數倒數

- Given 使用者已設定全域快捷鍵
  When 在其他 App 中按下該快捷鍵
  Then MacWipePlus 進入清潔模式，不將快捷鍵操作傳給前景 App

- Given 使用者尚未自訂全域快捷鍵
  When 使用者查看快捷鍵設定
  Then 預設快捷鍵為 `Control-Option-Command-M`，且使用者可以改成其他組合

- Given 清潔模式正在執行
  When App 被強制結束或 Mac 重新開機
  Then 系統恢復正常輸入，不留下持續攔截狀態

- Given macOS 使用繁體中文或英文
  When 使用者查看清潔模式畫面與設定
  Then UI 顯示對應語言的文字

## 開放問題

- 全域快捷鍵預設為 `Control-Option-Command-M`，並允許使用者自訂；若組合衝突，顯示錯誤並保留上一個有效設定。
- 自訂秒數限制為 10–3,600 秒；0、負數、小數、空值與超過 3,600 秒皆視為無效；不自動退出使用獨立選項表示。
- Accessibility／Input Monitoring 權限的實際最小需求與首次啟動引導文案；未授權時使用 overlay fallback，授權後啟用完整 Event Tap 攔截。
- App 是否需要 Apple Developer 簽章與 notarization，以便在其他 Mac 上無警告開啟。
